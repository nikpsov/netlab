# 🌐 Основы компьютерных сетей

Базовое руководство по сетевым протоколам, адресации и устройству компьютерных сетей.

---

## 📡 Модель OSI vs TCP/IP

| Уровень OSI | Модель TCP/IP | Протоколы / Технологии |
| :--- | :--- | :--- |
| Прикладной / Представительский | Прикладной (Application) | HTTP, HTTPS, SSH, DNS |
| Транспортный (Transport) | Транспортный | TCP, UDP |
| Сетевой (Network) | Межсетевой (Internet) | IP (IPv4/IPv6), ICMP |
| Канальный / Физический | Сетевой доступ (Network Access) | Ethernet, Wi-Fi, ARP |

---

## 🧮 IP-адресация и подсети

{{< callout type="info" >}}
**IPv4 Адрес** состоит из 32 бит (4 октетов). Маска подсети определяет, какая часть адреса относится к сети, а какая — к узлу.
{{< /callout >}}

Пример префикса CIDR `/24`:
- Маска: `255.255.255.0`
- Доступно адресов узлов: `254`
