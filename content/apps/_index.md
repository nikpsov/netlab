# 📱 Приложения и Клиенты VPN

Руководства по выбору, настройке и импорту конфигураций в клиенты для различных операционных систем.

## Поддерживаемые клиенты:
- **Sing-box** — универсальный клиент нового поколения для Android, iOS, Windows, macOS.
- **AmneziaVPN** — удобный клиент для быстрой настройки собственных серверов.
- **Nekoray / v2rayN** — мощные клиенты для ПК (Windows/Linux).
- **Clash / Clash Verge** — клиенты с гибкой политикой маршрутизации.
