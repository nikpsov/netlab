## ❓ Зачем нужен чистый DNS и почему без него Zapret не работает?

### Что такое DNS?
DNS (Domain Name System) — это «телефонная книга» интернета. Компьютеры не понимают буквенные имена вроде `instagram.com` или `x.com`. Чтобы открыть сайт, ПК сначала спрашивает у DNS-сервера: *«Какой IP-адрес у instagram.com?»*, и только потом отправляет туда сетевые пакеты.

### Проблема DNS Spoofing (Подмена DNS):
По умолчанию ваш компьютер использует DNS-сервер вашего провайдера. Когда вы запрашиваете заблокированный ресурс, провайдерский DNS отдаёт вам **фальшивый IP-адрес** (например, `0.0.0.0` или IP-адрес страницы-заглушки).

{{< callout type="warning" >}}
**ОЧЕНЬ ВАЖНОЕ ПОЯСНЕНИЕ:** Если ваш компьютер получил от провайдера фальшивый IP-адрес заглушки, то Zapret **НИКОГДА не поможет**, какая бы отличная стратегия у вас ни была! Пакеты отправляются в тупик на сервер заглушки, и "обманывать" DPI просто негде.
{{< /callout >}}

Для работы Zapret ваш компьютер **обязан получать настоящие, незаблокированные IP-адреса**.

## 🛡 Решение: Шифрованный DNS (DoH / DoT)

Обычные DNS-запросы отправляются в открытом виде по протоколу UDP на порт 53, поэтому провайдер может подменять их на лету. 

Чтобы защититься от подмены, используются зашифрованные протоколы:
- **DoH (DNS-over-HTTPS)**: Запросы маскируются под обычный защищенный веб-трафик HTTPS (порт 443).
- **DoT (DNS-over-TLS)**: Запросы передаются по шифрованному каналу TLS (порт 853).

## 🛠 Как настроить чистый DNS?

### Вариант 1: Включение DoH прямо в браузере (Самый быстрый вариант)
1. В **Chrome / Edge / Yandex**: Зайдите в *Настройки* → *Безопасность* → *Использовать безопасный DNS-сервер*.
2. Выберите провайдера (например, *Cloudflare 1.1.1.1* или *Google 8.8.8.8*).
3. В **Firefox**: Зайдите в *Настройки* → *Приватность и защита* → *DNS через HTTPS* → Выберите *Повышенная защита*.

### Вариант 2: Настройка на роутере Keenetic / OpenWrt
1. Зайдите в веб-интерфейс Keenetic → *Сетевые правила* → *Интернет-фильтры* → *Настройка DNS*.
2. Включите опцию **"Игнорировать DNS от провайдера"**.
3. Добавьте шифрованные DoH/DoT сервера:
   - **ControlD**: `https://freedns.controld.com/p0`
   - **OpenNameserver**: `https://ns1.opennameserver.org/dns-query`
   - **Yandex DoH**: `https://common.dot.dns.yandex.net/dns-query`

## 📝 Ручная пропись IP-адресов в файл `hosts`

Для некоторых сервисов (например, Instagram, Facebook, Twitter/X) безопаснее зафиксировать настоящие IP-адреса в системном файле `hosts` (`C:\Windows\System32\drivers\etc\hosts` или `/etc/hosts` на Linux/macOS):

```text
# Примеры рабочих IP для сервисов Meta и X
157.240.22.174 instagram.com
157.240.22.174 cdninstagram.com
157.240.22.35 facebook.com
104.244.42.1 twitter.com
104.244.42.1 x.com
```

После того как ваш компьютер начнет получать настоящие IP-адреса целевых серверов, Zapret сможет успешно выполнять десинхронизацию!
