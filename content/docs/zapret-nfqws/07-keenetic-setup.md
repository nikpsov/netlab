# Настройка nfqws2 на роутерах Keenetic (Entware + Netfilter)

## 📌 Источник материала
Материал основан на официальном репозитории [nfqws2-keenetic](https://github.com/nfqws/nfqws2-keenetic).

Запуск `nfqws2` прямо на роутере Keenetic — самый удобный способ защитить сразу **все устройства в доме** (смартфоны, ПК, планшеты и Smart TV) без установки софта на каждый девайс.

---

## 📋 Предварительные требования

Перед началом установки убедитесь, что ваш роутер Keenetic / Netcraze подготовлен:

1. **Установлена среда Entware**:
   - На встроенную память роутера или на подключенный USB-накопитель.
2. **Установлены модули ядра Netfilter**:
   - В веб-интерфейсе Keenetic перейдите в *Системный монитор* → *Компоненты операционной системы*.
   - Найдите и установите компонент **«Модули ядра подсистемы Netfilter»** (OPKG > Kernel modules for Netfilter).
3. **Отключены встроенные фильтры**:
   - В разделе *Интернет-фильтры* отключите NextDNS, SkyDNS, Яндекс.DNS и др.
4. **Настроен чистый DNS**:
   - В разделе *Сетевые правила* → *Интернет-фильтры* отметьте пункт **«Игнорировать DNS от провайдера»** и настройте DoH/DoT.

---

## 🛠 Пошаговый процесс установки

### Шаг 1: Подключение к Entware по SSH
Подключитесь к среде Entware роутера через SSH/Telnet клинетом (PuTTY, Terminal):

```bash
ssh 192.168.1.1 -l root -p 222
```
*(Логин по умолчанию: `root`, пароль по умолчанию: `keenetic`).*

### Шаг 2: Удаление старых версий (если устанавливались ранее)
Если на роутере стояла первая версия `nfqws-keenetic`, удалите её:

```bash
opkg remove nfqws-keenetic-web nfqws-keenetic
```

### Шаг 3: Установка пакета `nfqws2-keenetic`
Выполните команды обновления репозиториев и установки:

```bash
opkg update
opkg install nfqws2-keenetic
```

### Шаг 4: Конфигурация стратегии
Откройте конфигурационный файл служб `nfqws2`:

```bash
nano /opt/etc/nfqws2/nfqws2.conf
```

Вставьте вычисленную рабочую стратегию (для YouTube и Discord) и сохраните файл (`Ctrl + O`, затем `Ctrl + X`).

### Шаг 5: Запуск и проверка службы
Перезапустите службу `nfqws2`:

```bash
/opt/etc/init.d/S51nfqws2 restart
```

Проверьте статус работы службы:
```bash
/opt/etc/init.d/S51nfqws2 status
```

Теперь все устройства в вашей локальной сети, подключенные к роутеру Keenetic, смогут заходить на заблокированные ресурсы с максимальной скоростью!
