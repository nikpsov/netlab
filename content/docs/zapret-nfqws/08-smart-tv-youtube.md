## 📌 Источник материала
Подготовлено на основе базы знаний [rcd27/zapret2-mcp: Smart TV и YouTube диагностика](https://github.com/rcd27/zapret2-mcp/blob/main/knowledge/troubleshooting/smart-tv-youtube.md).

Одна из самых распространенных жалоб пользователей: *«Я настроил Zapret на роутере, на компьютере и смартфоне YouTube летает в 4K, а на телевизоре Samsung / LG приложение бесконечно крутит колесо загрузки. Почему?»*.

---

## ⚡ Корневая причина: TLS 1.2 vs TLS 1.3

Разгадка кроется в разнице протоколов шифрования, которые используют устройства:

- **ПК, браузеры, смартфоны (Android/iOS), Android TV (SmartTube)** используют современный протокол **TLS 1.3**.
- **Smart TV на операционных системах Samsung Tizen, LG WebOS, Hisense VIDAA** используют более старый протокол **TLS 1.2**.

| Платформа | Версия TLS | Работает ли обычная стратегия? |
| :--- | :--- | :--- |
| **ПК и Смартфоны** | TLS 1.3 | **ДА ✅** (работает почти всегда) |
| **Android TV (SmartTube)** | TLS 1.3 | **ДА ✅** |
| **LG WebOS** | **TLS 1.2** | ⚠️ Нужна подстройка под TLS 1.2 |
| **Samsung Tizen** | **TLS 1.2** | ❌ Очень чувствительна к десинхронизации |
| **Hisense VIDAA** | **TLS 1.2** | ⚠️ Нужна подстройка под TLS 1.2 |

Системы ТСПУ провайдеров обрабатывают соединения TLS 1.2 и TLS 1.3 по-разному. Стратегия, отлично сбивающая DPI на пакетах TLS 1.3, может быть совершенно неэффективной для TLS 1.2!

---

## 🔍 Диагностика совместимости стратегии с TLS 1.2

Чтобы проверить, подходит ли текущая стратегия для Smart TV, выполните команду `curl` с зафиксированной версией `TLS 1.2` (например, через SSH роутера или командную строку ПК):

```bash
curl --tlsv1.2 --tls-max 1.2 -I https://www.youtube.com
```

### Результат проверки:
- **Успешно (`HTTP/2 200` или `HTTP/2 301`)**: Страница ответила — стратегия подходит для Smart TV!
- **Ошибка (`curl: (28) SSL connection timeout`)**: Соединение зависло — стратегия **НЕ работает под TLS 1.2**, телевизор показывать видео не будет.

При подборе стратегии через `blockcheck` обращайте внимание на тесты `curl_test_https_tls12`.

## 🔌 КРИТИЧЕСКИ ВАЖНО: Борьба с агрессивным кэшем Smart TV

Операционные системы телевизоров (особенно **Samsung Tizen** и **LG WebOS**) агрессивно кэшируют приложение YouTube, DNS-запросы и незакрытые сетевые сокеты.

{{< callout type="warning" >}}
Если вы сменили стратегию на роутере и просто выключили и включили телевизор с пульта — **изменения НЕ применятся!** Телевизор продолжит использовать старое зависшее соединение из памяти.
{{< /callout >}}

### Обязательный алгоритм сброса кэша Smart TV:
1. Вымените стратегию на роутере и запустите службу `nfqws2`.
2. **Физически выдерните шнур питания телевизора из розетки**.
3. Подождите **15 секунд** (чтобы разрядились конденсаторы и очистилась оперативная память ТВ).
4. Включите вилку обратно в розетку.
5. Запустите приложение YouTube.

После этого телевизор создаст новое сетевое соединение с использованием свежей стратегии `nfqws2`!
