## ❓ Что такое Zapret простым языком?

**Zapret** — это бесплатная программа с открытым исходным кодом, которая позволяет обходить цензуру и замедления сайтов в интернете **без покупки VPN и без аренды сторонних серверов**.

### Простая аналогия:
Представьте, что вы отправляете письмо по почте, но на почтамте сидит контролёр, который смотрит на обложку конверта. Если на конверте написано название заблокированного сайта (например, `youtube.com` или `discord.com`), контролёр просто выбрасывает письмо в корзину.

- **Обычный VPN** — это передача письма через секретного курьера в другой стране. Письмо идет долго, курьеру нужно платить, а скорость может быть низкой.
- **Zapret** — работает прямо у вас дома! Он слегка "складывает" или хитрым образом надрезает конверт перед отправкой. Контролёр провайдера не может прочитать заголовок на конверте и пропускает письмо дальше. Когда письмо доходит до получателя (сервера), тот легко раскрывает конверт и читает ваше сообщение.

## 🔑 Главное отличие Zapret от VPN

{{< callout type="info" >}}
**Запомните:** Zapret **НЕ шифрует весь ваш интернет-трафик** и **НЕ скрывает ваш IP-адрес**. Он работает исключительно с пакетами данных, сбивая с толку системы фильтрации провайдера (DPI).
{{< /callout >}}

| Характеристика | Обычный VPN | Zapret / nfqws |
| :--- | :--- | :--- |
| **Принцип работы** | Трафик идет через удаленный сервер за границей | Трафик идет напрямую к целевому сайту |
| **Скорость интернета** | Часто снижается (зависит от сервера VPN) | **Максимальная (ваша провайдерская скорость)** |
| **Стоимость** | Требуется платная подписка или арендованный VPS | **Бесплатно** |
| **Смена IP-адреса** | Меняет ваш IP на IP-адрес другой страны | **Не меняет IP-адрес** (вы выходите под своим IP) |

## 🚀 В чем разница между Zapret 1 и Zapret 2?

В 2024–2025 годах автор проекта (`bol-van`) выпустил полностью переписанную вторую версию программы — **Zapret 2**.

1. **Zapret 1 (`nfqws`)**:
   - Находится в статусе **EOL (End-of-Life)**. В нем больше не появляются новые функции.
   - Жестко зашитая логика в коде C. Все настройки задаются только через флаги командной строки.
2. **Zapret 2 (`nfqws2`)**:
   - Активно развивающаяся версия.
   - **Встроенный движок Lua**: Позволяет писать сложные скрипты обхода на языке Lua, гибко реагировать на изменения систем фильтрации и задавать множественные профили под разные сайты.

## 📦 Каталог репозиториев и утилит по платформам

Ниже собраны основные открытые репозитории, оригинальные ядра и популярные готовые сборки для различных операционных систем и устройств:

### 1. Официальные репозитории Zapret
- 🔗 **[bol-van/zapret2](https://github.com/bol-van/zapret2)** — Главный репозиторий Zapret 2 (`nfqws2`, поддержка Lua, мультипрофили).
- 🔗 **[bol-van/zapret](https://github.com/bol-van/zapret)** — Исходная первая версия Zapret 1 (в режиме EOL).

### 2. Готовые сборки и GUI под Windows
- 🔗 **[Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)** — Самая популярная готовая сборка Zapret для Windows с пакетом `.bat` скриптов для YouTube и Discord.
- 🔗 **[Zapret GUI / Zapret 2 GUI](https://publish.obsidian.md/zapret)** — Графические интерфейсы (GUI) для управления службой `winws` без использования командной строки.
- 🔗 **[Valedik/GoodbyeDPI](https://github.com/Valedik/GoodbyeDPI)** — Классическая утилита от Valedik для пассивного обхода DPI под Windows (AntiDPI / GoodbyeDPI).

### 3. Решения для роутеров (Keenetic, OpenWrt, Padavan)
- 🔗 **[nfqws/nfqws2-keenetic](https://github.com/nfqws/nfqws2-keenetic)** — Официальный адаптированный пакет `nfqws2` для роутеров Keenetic / Netcraze через Entware.
- 🔗 **[Waujito/youtubeUnblock](https://github.com/Waujito/youtubeUnblock)** — Специализированная эффективная утилита обхода DPI для OpenWrt и Linux.

### 4. Мобильные устройства (Android)
- 🔗 **[bedheaders/ByeByeDPIAndroid](https://github.com/bedheaders/ByeByeDPIAndroid)** — Популярное приложение для Android, реализующее десинхронизацию пакетов через локальный VPN-сервис без необходимости Root-прав.
- 🔗 **[hagezi/ByeByeDPI](https://github.com/hagezi/ByeByeDPI)** — Сборки и фильтры ByeByeDPI.

### 5. macOS и Linux
- 🔗 **[xvzc/SpoofDPI](https://github.com/xvzc/SpoofDPI)** — Быстрый и лёгкий прокси-десинхронизатор DPI на языке Go для macOS и Linux.
